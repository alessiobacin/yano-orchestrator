# Ponytail

Source: https://github.com/dietrichgebert/ponytail
Commit: `e3ba2aa6f1e6f0bc4d69eb09c9f0d0a93af56156` (2026-09-15 snapshot).
`ponytail/SKILL.md` is copied unchanged from upstream `skills/ponytail/SKILL.md`.
MIT license retained alongside this file.

Yano injects this skill for every role on every turn by default (`full`).
`yano ponytail off` disables it for the current project; `--global` changes
the inherited default. Project overrides take precedence. User instructions
and existing safety, review, documentation and testing requirements remain binding.
